# Cosmic Quest website

## Publish or update with GitHub Pages
1. Sign in to GitHub and open your `cosmic-quest` repository.
2. Choose **Add file → Upload files**. Upload the updated `index.html`, `style.css`, and `script.js` (and `.nojekyll` if it is not already there).
3. Commit the changes to the `main` branch. GitHub Pages will rebuild the website automatically.
4. Open **Settings → Pages** to find your published website address.

## Included features
- Four featured rides: Cosmic Half Spin, Orbit Spinner, AI Galaxy Tour Train and Zero-Gravity Adventure Dome.
- Aerocity Cockpit and VR: Aviator flight simulation.
- Smart operations: IoT and sensors, mobile apps, AI-powered maintenance, smart security and data-driven insights.
- Sustainability: renewable energy, waste management, water conservation, green buildings and eco-friendly transport.
- Food, merch and engagement: Galactic Cuisine, Custom Merch and Galaxy Passport.
- Responsive navigation and a demo ticket calculator.
